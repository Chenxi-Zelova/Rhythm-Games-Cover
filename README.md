# 为什么制作这个项目

因为考虑到目前osulazer没加入对排位模式的遮罩mod，所以在俺寻思之力下使用AI完成了这个项目，并又额外制作了左右遮罩，也许可以用于打喵斯快跑。

# 注意事项

请在确保不会影响部分有共同快捷键的窗口下运行，以免造成文件或进程损失。
快捷键可能会拦截输入，请在启用关闭窗口的状态下下再进行输入。

# 黑色置顶窗口

一个用于显示黑色覆盖窗格和定位线的 Windows 小工具。窗口始终置顶、鼠标点击穿透，不会抢占后方程序的焦点。

## 启动

双击 `StartBlackOverlay.vbs` 即可启动。启动器会隐藏 PowerShell 控制台窗口。

也可以在 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\BlackOverlay.ps1
```

## 快捷键

方向键调整步长为 40 像素。快捷键在全局生效。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+1` | 切回默认单窗口布局 |
| `Ctrl+Alt+2` | 上下分屏 |
| `Ctrl+Alt+3` | 左右分屏 |
| `Ctrl+←/→/↑/↓` | 缩窄 / 加宽 / 缩矮 / 增高当前总窗口 |
| `Shift+←/→/↑/↓` | 移动当前总窗口 |
| `Ctrl+1/2+方向键` | 分屏时调整第一 / 第二窗格大小 |
| `Shift+1/2+方向键` | 分屏时移动第一 / 第二窗格 |
| `Alt+1/2+方向键` | 分屏时移动第一 / 第二窗格的线 |
| `Ctrl+Space` | 切换当前布局中所有线条的显示 |
| `Ctrl+1/2+Space` | 分屏时切换第一 / 第二窗格的线条显示 |
| `Alt+Space` | 切换当前布局中所有线条的横竖方向 |
| `Alt+1/2+Space` | 分屏时切换第一 / 第二窗格线条的横竖方向 |
| `Alt+↑/↓` | 上下移动当前布局中的线条 |
| `Alt+←/→` | 左右移动当前布局中的线条 |
| `Shift+Space` | 隐藏 / 恢复窗口 |
| `Ctrl+F5` | 显示重置确认；再次按下确认，`Esc` 取消 |
| `右 Alt+0–9` | 保存当前全部布局到对应编号预设 |
| `右 Shift+0–9` | 载入对应编号预设 |

带数字的组合键请按住修饰键和数字，再按方向键或空格。例如，按住 `Ctrl+1` 后按 `→` 调整第一窗格；按住 `Alt+2` 后按空格切换第二窗格线条方向。

保存成功和读取成功时会显示对应预设编号。若编号已有文件，第一次保存会询问是否覆盖；再次按同一组右 Alt+数字确认，按 `Esc` 取消。

## 窗口说明

- 默认窗口居中显示，大小为 `480×300`；屏幕较小时会相应缩小。
- 上下/左右分屏之间保留固定 40 像素间隙；窗格可沿任意方向独立移动并越出总窗口范围，反向使用对应快捷键可移回。两个窗格仍不能互相重叠。
- 默认线条为白色横线，位于窗格中间；方向、位置和显示状态可分别调整。
- 默认、上下分屏、左右分屏的总窗口位置/尺寸、间距、窗格位置/尺寸及线条属性各自独立保存。状态在程序运行期间保留；退出后不会写入磁盘。
- 预设文件为 `preset-0.rgc` 至 `preset-9.rgc`，保存在程序脚本所在文件夹；保存到已有编号会覆盖该预设。
- 重置只作用于当前布局：恢复该模式下的窗格位置/尺寸和线位置；保留当前分屏模式及线条横竖方向，并显示线条。
- 窗口没有边框，鼠标操作会穿透到后方程序；请使用快捷键移动和调整大小。
- 可在任务栏找到窗口，右键选择“关闭窗口”退出。
- `Shift+空格` 只隐藏窗口，不会退出程序；再次按下可恢复显示。
- 建议同时只运行一个实例，避免全局快捷键或键盘钩子冲突。
